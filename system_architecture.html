🔮 M7: Hybrid Fusion Architecture (Detailed)
Step 1: Feature Projection
  • Project image features: 512 → 256 dimensions
  • Project text features: 1024 → 256 dimensions
  • Aligns modalities to common space
Step 2: Cross-Modal Attention
  • 4-head multi-head attention mechanism
  • Query: Image features (B, 1, 256)
  • Key/Value: Text features (B, 1, 256)
  • Output: Attended image features
  • Learns cross-modal dependencies
Step 3: Dynamic Gating Network
  • Input: Concatenated [image, text] features (512D)
  • 2-layer MLP with ReLU activation
  • Output: 2D weights with softmax (α_img, α_text)
  • Learns sample-specific modality importance
  • Adaptive weighting per instance
Step 4: Weighted Fusion
  • Weighted sum: fused = α_img × f_img + α_text × f_text
  • Concatenate: [attended_img, weighted_text]
  • Fusion layer: 512D → 256D
Step 5: Classification Head
  • 2-layer MLP: 256 → 128 → 2 classes
  • ReLU activation & dropout (0.3)
  • Output: Logits for binary classification
# Pseudo-code for Hybrid Fusion Forward Pass img_proj = Linear(img_features) # 512 → 256 txt_proj = Linear(txt_features) # 1024 → 256 attended_img = MultiHeadAttn( # Cross-modal attention query=img_proj, key=txt_proj, value=txt_proj ) concat = Concat([img_proj, txt_proj]) # → 512D weights = Softmax(MLP(concat)) # → [α_img, α_text] fused = Concat([ attended_img, weights[0]*img_proj + weights[1]*txt_proj ]) # → 512D output = Classifier(fused) # → 2 classes

🔍 Key Research Findings

  1. Multimodal Superiority: Hybrid fusion (M7) achieves +5.9% F1 over text-only baseline, demonstrating complementary modality benefits
  2. Text Modality Dominance: Text-only (M1) outperforms image-only (M2) by 16.6% F1, revealing CLIP's Devanagari blindness
  3. Typography Information: Comparison of M2 vs M3 quantifies 5.8% F1 contribution from in-image text features
  4. Ensemble Failure: Bagging (M6) underperforms in extreme low-resource setting (N=854), challenging ensemble assumptions
  5. Adaptive Fusion Works: Dynamic gating (M7) outperforms fixed-weight fusion (M5) by +3.2% F1
  6. Metric Selection Matters: Accuracy misleads in imbalanced setting (M1 highest accuracy but not best F1)

💻 Technical Implementation Stack

Core Libraries:
  • PyTorch 2.0+: Deep learning framework
  • Transformers (Hugging Face): Pre-trained models (CLIP, BGE-M3)
  • Scikit-learn: Cross-validation, metrics, stratification
  • Pandas & NumPy: Data manipulation
  • Matplotlib & Seaborn: Visualization
Model Checkpoints:
  • CLIP: openai/clip-vit-base-patch32
  • BGE-M3: BAAI/bge-m3 (superior Indic support)
  • Alternative: intfloat/e5-large (compared in ablation)
Hardware Requirements:
  • GPU: NVIDIA GPU with 8GB+ VRAM (RTX 3070/V100/T4)
  • Training time: ~2-3 hours per fold (5 folds total)
  • Inference: <50ms per sample on GPU

🔄 Complete System Workflow

  1. Data Loading: Load CSV (Image, Text, Label) + image folder → MultimodalDataset
  2. Stratified Split: 5-fold cross-validation with stratified sampling (maintains class balance)
  3. Preprocessing: Apply CLIP transforms (images) + BGE-M3 tokenization (text)
  4. Feature Encoding: Extract features via CLIP ViT-B/32 (images) + BGE-M3 (text)
  5. Fusion: Apply selected fusion strategy (M1-M8 configurations)
  6. Training: Forward pass → Loss computation → Backprop → Optimizer step
  7. Validation: Evaluate on fold validation set → Early stopping check
  8. Aggregation: Average metrics across 5 folds → Report mean ± std
  9. Inference: Load best checkpoint → Predict on test set → Generate submission
